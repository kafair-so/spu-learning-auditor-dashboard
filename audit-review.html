Local Edition

สำหรับใช้งานนอกสถานที่ ตรวจรายวิชา เก็บรายงาน และส่งออกไฟล์ผลรูปแบบเดิมบนเครื่องหรือเว็บไซต์ฐานข้อมูลเดิม

เหมาะกับ: ตรวจที่บ้าน / เก็บไฟล์เอง
1

ดาวน์โหลดและแตกไฟล์

ดาวน์โหลด ZIP แล้วคลิกขวาเลือก Extract All… และเก็บโฟลเดอร์ไว้ในตำแหน่งถาวร

2

เปิดหน้า Extensions

เปิด Chrome แล้วพิมพ์ chrome://extensions ในแถบที่อยู่

3

เปิด Developer mode

เปิดสวิตช์ Developer mode ที่มุมขวาบน จากนั้นเลือก Load unpacked

4

เลือกโฟลเดอร์ที่แตกไฟล์

เลือกโฟลเดอร์ที่มีไฟล์ manifest.json แล้วปักหมุดไอคอน Extension บน Chrome

การอัปเดตเวอร์ชัน

ดาวน์โหลด ZIP ของรุ่นเดิมที่ใช้งานอยู่เท่านั้น แตกไฟล์ แล้วกดปุ่มรีโหลด ⟳ ของ Extension นั้นในหน้า chrome://extensions ก่อนเริ่มตรวจรอบถัดไป
